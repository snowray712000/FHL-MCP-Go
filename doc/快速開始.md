# 快速開始

適用 0.0.0.21 以後。所有指令都在解壓縮後的資料夾執行（Windows 用 `.\fhl-mcp.exe`，Mac／Ubuntu 用 `./fhl-mcp`）。

## 第一次使用

1. 連接 AI 工具（做一次就好，所有專案都能用）：

   ```sh
   fhl-mcp setup
   ```

   在終端機執行會問你要連 Claude Code、Codex 或兩者；也可以直接指定 `--client claude` 或 `--client codex`。
   找不到某個工具的命令列程式時，會印出你可以手動執行的指令，不會自己安裝任何東西。
   也可以雙擊 `首次設定.cmd`（Windows）或 `Setup.command`（Mac）。

2. 啟動服務（要查經時才開，關掉終端機視窗或按 Ctrl+C 就停；重開機不會自動啟動）：

   ```sh
   fhl-mcp serve
   ```

   也可以雙擊 `啟動-FHL-MCP.cmd`（Windows）或 `Start-FHL-MCP.command`（Mac）。

3. 在 Claude Code／Codex 重新載入 MCP，或開一個新的工作階段。

## 平常會用到的指令

| 指令 | 作用 |
| --- | --- |
| `fhl-mcp status` | 看服務有沒有在跑（`--json` 輸出 JSON） |
| `fhl-mcp stop` | 停止服務（只會停本服務；會先驗證身分） |
| `fhl-mcp doctor` | 診斷：環境、設定、服務、信望愛網站、客戶端登錄（`--offline` 略過連網） |
| `fhl-mcp disconnect` | 移除 Claude Code／Codex 裡本服務的登錄，不動其他 MCP |
| `fhl-mcp cache clear` | 清除回應快取 |

## 注意事項

- 服務固定使用 `127.0.0.1:8081`，只接受本機連線。埠被別的程式占用時會明確失敗，不會偷偷換埠；要換埠請用 `--port`，並用同樣的 `--port` 重新 `setup`。
- 用了 `--data-dir` 或 `--port` 啟動的話，`status`、`stop`、`doctor` 也要加上同樣的參數才找得到。
- 升級：先 `fhl-mcp stop`，換掉程式，再 `fhl-mcp serve`。網址沒變就不用重新 `setup`。
- 退出使用：先 `fhl-mcp disconnect`，再刪除程式資料夾；快取與狀態在系統使用者快取目錄的 `fhl-mcp`（或你指定的 `--data-dir`），可自行刪除。
- 在 WSL 內，`127.0.0.1` 與 Windows 端不一定相通；客戶端與服務要在同一個環境，登錄也要各做一次。
