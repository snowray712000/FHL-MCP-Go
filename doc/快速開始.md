# 快速開始

適用 1.1.1 以後。所有指令都在解壓縮後的資料夾執行（Windows 用 `.\fhl-mcp.exe`，Mac／Ubuntu 用 `./fhl-mcp`）。

## 取得與驗證

### 從 github 下載

- 下載對應你電腦的壓縮檔（Windows `…_windows_amd64.zip`、Apple 晶片 Mac `…_darwin_arm64.tar.gz`、Ubuntu `…_linux_amd64.tar.gz`），解壓縮到任何地方（路徑有中文或空白也可以）。
- 同一處的 `SHA256SUMS.txt` 可以核對檔案沒被改過：Windows 用 `Get-FileHash 檔名`，Mac 用 `shasum -a 256 檔名`，Ubuntu 用 `sha256sum 檔名`，結果要和 `SHA256SUMS.txt` 內該檔那一行相同。
- 目前沒有數位簽章與 Apple 公證，第一次執行時 Windows（SmartScreen）或 macOS（Gatekeeper）可能跳出警告；請依系統提示確認來源後再放行，不需要也不建議關閉任何系統防護。這一點尚未在每種系統上逐一驗證。
- 授權：GPL-3.0-or-later，條款見 `LICENSE`；內含的第三方函式庫與原 Python 版的聲明見 `THIRD_PARTY_NOTICES.md`。聖經與網站內容的著作權不在此授權範圍內。

### 使用 npm 安裝

- 使用 `sudo npm i -g @fhlnet/fhl-mcp`
- 安裝好後，驗證則透過 `fhl-mcp version`
- 連接 Claude Code 或 Codex，使用 `fhl-mcp setup`

## Ubuntu 解壓縮與執行

在終端機（Ctrl+Alt+T）進入檔案所在資料夾，例如下載資料夾：

```sh
cd ~/Downloads
tar -xzf fhl-mcp-go_<版本>_linux_amd64.tar.gz
cd fhl-mcp-go_<版本>_linux_amd64
./setup.sh      # 首次設定，連接 Claude Code / Codex
./start.sh      # 啟動服務
```

`<版本>` 換成實際檔名，檔名打一半按 Tab 會自動補完。`tar -xzf` 就是解壓縮 `.tar.gz`。`setup.sh`、`start.sh` 只是包裝 `./fhl-mcp setup`、`./fhl-mcp serve`，直接打後者也行。Ubuntu 沒有雙擊入口，請在終端機執行。Mac 的做法相同（檔名換成 `darwin_arm64`，也可雙擊 `.command`）。

## 第一次使用

1. 連接 AI 工具（做一次就好，所有專案都能用）：

   ```sh
   fhl-mcp setup
   ```

   在終端機執行會問你要連 Claude Code、Codex 或兩者；也可以直接指定 `--client claude` 或 `--client codex`。
   找不到某個工具的命令列程式時，會印出你可以手動執行的指令與安裝方式，不會自己安裝任何東西。要先裝好才能連接（需要 Node.js）：

   ```sh
   npm i -g @anthropic-ai/claude-code   # Claude Code
   npm i -g @openai/codex                # Codex
   ```

   裝好後開一個新的終端機視窗再執行 `fhl-mcp setup`。已安裝卻仍找不到時，多半是 npm 全域資料夾（`npm prefix -g` 可查）不在 PATH。
   也可以雙擊 `首次設定.cmd`（Windows）、`Setup.command`（Mac），Ubuntu 用 `./setup.sh`。

2. 啟動服務（要查經時才開，關掉終端機視窗或按 Ctrl+C 就停；重開機不會自動啟動）：

   ```sh
   fhl-mcp serve
   ```

   也可以雙擊 `啟動-FHL-MCP.cmd`（Windows）、`Start-FHL-MCP.command`（Mac），Ubuntu 用 `./start.sh`。

3. 在 Claude Code／Codex 重新載入 MCP，或開一個新的工作階段。

## 平常會用到的指令

| 指令 | 作用 |
| --- | --- |
| `fhl-mcp status` | 看服務有沒有在跑（`--json` 輸出 JSON） |
| `fhl-mcp stop` | 停止服務（只會停本服務；會先驗證身分） |
| `fhl-mcp doctor` | 診斷：環境、設定、服務、信望愛網站、客戶端登錄（`--offline` 略過連網） |
| `fhl-mcp disconnect` | 移除 Claude Code／Codex 裡本服務的登錄，不動其他 MCP |
| `fhl-mcp cache clear` | 清除回應快取 |

## 注意事項

- 服務固定使用 `127.0.0.1:8081`，只接受本機連線。埠被別的程式占用時會明確失敗，不會偷偷換埠；要換埠請用 `--port`，並用同樣的 `--port` 重新 `setup`。
- 用了 `--data-dir` 或 `--port` 啟動的話，`status`、`stop`、`doctor` 也要加上同樣的參數才找得到。
- 升級：先 `fhl-mcp stop`，換掉程式，再 `fhl-mcp serve`。網址沒變就不用重新 `setup`。
- 退出使用：先 `fhl-mcp disconnect`，再刪除程式資料夾；快取與狀態在系統使用者快取目錄的 `fhl-mcp`（或你指定的 `--data-dir`），可自行刪除。
- 在 WSL 內，`127.0.0.1` 與 Windows 端不一定相通；客戶端與服務要在同一個環境，登錄也要各做一次。
